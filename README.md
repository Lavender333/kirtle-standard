# Kirtle Standard

Responsive home-care website with brand artwork, service checklists, add-on pricing, client forms, and an email inquiry form.

## Preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this directory. No build or dependencies are required.

## GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**.

## Editing
Page content, styles, and interactions are in `index.html`. Images and original forms are in `assets/`. The inquiry form prepares an email; visitors must send it from their email app. It does not store submissions or confirm bookings.
